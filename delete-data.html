데이터 삭제 요청

앱: Yangdoku: No Ad Breaks (양도쿠) · 개발자: The Mallang Games

1. 기기에 저장된 데이터 — 앱을 삭제하면 함께 지워집니다

  1. 기기에서 Yangdoku 앱을 길게 눌러 삭제(제거) 합니다.
  2. 진행 상황, 남은 힌트, 구매한 도구의 소유 표시, 설정, 앱 동작 기록이 함께 삭제됩니다.

진행 상황만 되돌리려면 앱 안의 설정 → 초기화 를 쓸 수 있습니다. 구매한 항목은 초기화로 지워지지 않습니다.

2. 광고 식별자 — 기기 설정에서 초기화합니다

  1. 안드로이드 설정 → 개인 정보 보호 → 광고 로 들어갑니다.
  2. 광고 ID 삭제 또는 광고 ID 초기화 를 누릅니다.

3. 문의로 보낸 내용과 서버 운영 이벤트 — 이메일로 요청하시면 확인합니다

  1. koobo0806@gmail.com 으로 메일을 보냅니다.
  2. 제목에 데이터 삭제 요청 이라고 적고, 문의를 보낸 날짜나 내용을 알려 주시면 찾기 쉽습니다.
  3. 문의 내용은 확인 후 30일 안에 삭제하고 회신합니다. 서버에 전송된 운영 이벤트는 익명 설치 ID 기준으로 찾을 수 있는 범위에서 삭제하거나 집계에서 분리합니다.
